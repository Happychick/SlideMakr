# AGENTS.md

SlideMakr's agent guidance lives in **[CLAUDE.md](CLAUDE.md)** — the single
constitution shared by all coding agents (Claude Code, Codex, etc.). Read it first.

It covers: the goal (make the slides the user asked for, in the least time) and how
success is measured (the `evals/` metric), commands, key patterns, gotchas, and a
map to the slide-making knowledge (`app/skills/google_slides.md`), the
tool catalog (`docs/TOOLS.md`), and the roadmap (`PROJECT_PLAN.md`).

Do not duplicate guidance here — update CLAUDE.md so both entry points stay in sync.
